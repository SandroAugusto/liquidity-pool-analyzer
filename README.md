# Fee growth snapshots

Hourly snapshots of the public Orca WBTC/SOL Whirlpools, appended by
`.github/workflows/fee-snapshots.yml` on `main` to `fee-growth/YYYY-MM.jsonl`.
Format and rationale: `docs/adr/0007-fee-growth-snapshots.md` on `main`.

Public protocol accounts only: nothing here concerns any wallet or position.
This branch has no shared history with `main` and is never merged into it.
